<h2 id="getting-started" align="center">Getting Started</h2>

<h3 align="left">Prerequisites</h3>

<p>
  To run the programs in this repository, you need to have Python installed on your system. You can download the latest version of Python from <a href="https://www.python.org/">python.org</a>.
</p>

<h3 align="left">Installation</h3>

<pre>
<code>
# Clone this repository to your local machine
git clone https://github.com/Prince-codes/Basic-Python-Program.git

# Navigate to the project directory
cd Basic-Python-Program

# Run any Python program
python &lt;program_name&gt;.py
</code>
</pre>
